# 09. 일일 대사 (8주 차)

> 진행 방식 (2026-11-25): 개발자가 먼저 채운다 → Claude가 장애 질문으로 하나씩 리뷰. 대사는 흐름(홉)이 아니라 **배치**라 템플릿을 대사용으로 바꿨다. 모르는 칸은 "모름"

## 0. 지금 시스템에 있는 것 (Claude 정리, 사실만)

- core 원장: 타행 출금 = 고객 예금 → `타행이체 미정산` 계정 (원장 키 = 송금 ID), 취소 = 역분개 (원장 키 = `{송금ID}-cancel`, `reverses_entry_id`로 원래 출금을 가리킴)
- transfer: 타행 송금 상태 (`COMPLETED` · `CANCELLED` · `FAILED` · 중간 상태들), 출금 전표 ID(`core_entry_id`)·취소 전표 ID(`cancel_entry_id`)
- bank-mock: 메모리에 송금 키별 판정(ACCEPTED/REJECTED) 저장, 송금 키 단건 조회 API. **하루치 거래 내역 API는 없다** (`docs/domain/README.md`의 "하루 거래 내역 제공(대사용)"은 아직 미구현). 재시작하면 기록이 사라진다 (결정 6)
- 차액결제(정산 자금 이동)는 흉내 내지 않기로 했다 (`docs/domain/README.md`) → 미정산 계정은 지금 계속 쌓이기만 한다 (S-4: "미정산 3만 남음 = 정상")
