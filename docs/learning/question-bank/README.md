# 질문 은행

세션 중 나눈 기술 질답을 **질문 형태**로 모아 둔다. 설명은 `docs/learning/<주제>.md`, 여기는 그걸 다시 꺼내 보는 질문.

- 저장: `/save-qa [주제]` (`.claude/skills/save-qa`)
- 연습: `/quiz-me [주제 | random | weak | 개수 | ID]` (`.claude/skills/quiz-me`) → 결과는 `_history.md`
- 혼자 볼 때: 질문만 읽고 답을 말해 본 뒤 "답 핵심"을 펼친다 (GitHub에서 접혀 보인다)

## 질문 유형

개념 / 꼬리 / 상황 적용 / 장애 / 비교 / 우리 프로젝트. 난이도 ★ 기본, ★★ 꼬리·적용, ★★★ 내부 동작·여러 개념을 엮음
