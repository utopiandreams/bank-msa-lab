# 배운 것 정리

세션에서 새로 배운 개념을 **내 말로** 정리하는 곳. 복기와 면접 준비용이다.

- 내가 쓰고, Claude가 리뷰한다 (틀린 부분, 빠진 부분, 면접 꼬리 질문). Claude가 대신 쓰지 않는다
- 파일: `YYYY-MM-DD-<주제>.md`. 한 파일에 주제 여러 개도 괜찮다
- 완벽하게 쓰려고 하지 않는다. "이해한 만큼 쓰고, 모르는 건 모른다고 적기"가 리뷰받기 제일 좋은 글이다
- 코드는 짧은 조각만. 전체는 커밋 해시로 링크

## 쓰는 틀 (주제마다)

```markdown
## <주제>

**한 줄 요약:** 면접에서 30초 안에 말할 수 있는 형태로

**왜 필요한가:** 이게 없으면 실무에서 어떤 사고가 나나

**어떻게 했나:** 우리 코드에서는 (파일·커밋)

**다른 선택지:** 왜 그걸 안 골랐나

**아직 헷갈리는 것:**
```

### 1. 트랜잭션과 멱등
- posting 모듈은 왜 있나? account가 ledger를 직접 부르면 안 되나?

- 멱등 키가 뭐고, 같은 키·같은 내용 / 같은 키·다른 내용이 오면 각각 어떻게 되나? 왜 다른 내용을 성공으로 응답하면 안 되나?
- 송금을 출금 거래 + 입금 거래 2건으로 남기면 뭐가 문제인가?

### 2. 동시 중복 요청

- 재시도를 무한히 하지 않고 한 번만 하는 이유는? 그 재시도 로직의 한계는?

### 3. 동시성 테스트 작성법

### 4. 400 vs 500, 검증은 어디서
